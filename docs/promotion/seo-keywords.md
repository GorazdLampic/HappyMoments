## Technical SEO Recommendations

### Immediate (no-cost, high impact)
1. **Add hreflang tags** for all 21 languages — critical for international SEO
2. **Structured data (JSON-LD)**: SoftwareApplication schema for the main page
3. **Open Graph / Twitter Card meta tags** with milestone card images
4. **Sitemap.xml** including all language variants
5. **Canonical URLs** to prevent duplicate content across language versions

### Short-term (create SEO landing pages)
6. Create `/milestone/1-billion-seconds` as a standalone calculator page (this is the #1 organic opportunity)
7. Create `/calculator/age-in-days` as a simple tool page
8. Add `<title>` and `<meta description>` to every page (currently missing or generic)
9. Blog section at `/blog/` with the Tier 1 articles listed above

### Medium-term (content marketing)
10. Publish 2 blog posts per month targeting long-tail keywords
11. Create language-specific landing pages for top 5 non-English markets
12. Build cultural number explainer pages that link to the calculator
13. Target seasonal keywords (New Year, Valentine's Day, birthday season)
