v2.0 Update: 3 tabs instead of 2 + sub-toggle

Lesson learned (v1.4 → v2.0): The 2-tab model with a sub-toggle on Home (Me / Group) was confusing — users didn't discover the sub-toggle, and mixing personal and combined milestones on one tab still felt crowded. The fix: give each concern its own tab.

Me = all individual milestones for all people, sorted by time proximity. No hero card — avoiding the problem of one person always being "featured" over others.
Together = combined/group milestones (when ages add up to special numbers). Group sub-tabs when 2+ groups exist.
Edit = manage people, groups, and settings. Group editor is a full-screen overlay.

Why this structure

  • 3 tabs, each with one clear purpose: Me = see milestones. Together = see combined milestones. Edit = manage data. No sub-toggles or hidden modes.
  • Labels + icons: Each tab has both an icon and a text label. This is more discoverable than icon-only (Instagram/WhatsApp use labels too).
  • Gold active indicator: Active tab has gold icon + label. Inactive tabs are gray. Consistent with the gold = "things that matter" design rule.
  • No profile icon: Settings live on the Edit tab. No separate profile concept needed — the app is local-first with no accounts.
Tab visual design:
• A thin top border separating the tab bar from content (1px, var(--border))
• Icons + text labels: Me (⭐), Together (👥), Edit (✎)
• Active tab: gold icon + gold label. Inactive: gray icon + gray label.
• Fixed at bottom of viewport (sticky), never scrolls away.
• Tab bar height: 56px (Apple HIG minimum 49pt, Material Design 80dp — 56px is a good compromise).

No Hero Card (v2.0 decision)

Why no hero card: In daily use, all milestones are treated equally. A hero card would always feature one person over others — creating the uncomfortable feeling that the app "prefers" your mom over your partner. The time-chunked list naturally surfaces the soonest milestones at the top. The hero concept is reserved for the onboarding reveal, where it creates the "wow" moment.

Time-Chunked Milestone List

Milestones grouped by: This week / This month / Later

Each cell: person name + milestone value (gold mono) + date with ordinal suffixes ("Sep 7th"). Year shown only if different from current year. Tap milestone → gold highlight (tc-selected) + sticky share bar above tabs → Share button → native share picker. Text also copied to clipboard.

Person Filter

Row of person buttons at top of Me tab. "All" selected by default. Tap a person to filter milestones to just that person. Tap again to show all. The milestone list updates immediately to show only the selected person's milestones (v55 fix: filter is now applied to the actual milestone rendering, not just the UI buttons).

Together Tab

Combined/group milestones live on their own tab (not a section on Me tab). When 2+ groups exist, group sub-tabs appear at the top of the Together tab. Group name has pencil icon → tapping opens the full-screen group editor.

Second-group nudge (v55): When only 1 group exists, the Together tab shows a "Got another circle?" card with a "+ New group" button. This encourages users to create a second group (Friends, Colleagues, etc.) for richer combined milestones. The nudge disappears automatically once 2+ groups exist.

Edit Tab

Group cards with members listed. Each card tappable to open the group editor (full-screen overlay). "+ New group" button. Settings below the group cards, organized as:

  1. Theme: tiny inline dark/light toggle (no separate section)
  2. Reminders: single checkbox
  3. "Advanced settings ▼" (collapsed by default): Number Patterns + Custom Numbers

Removed (v52, per Matej Guid's UX review): Invite Friends, Send Feedback, Save Settings button, Reset All Data. These added visual weight without clear user benefit at this stage.

Version number and build timestamp displayed in the app footer at the bottom of the Edit tab.

Group Editor (Full-Screen Overlay)

  • Group name: editable text field at top
  • Members: inline editable name + date fields for each member
  • Add member: name + date input row
  • Remove member: × button on each member
  • Delete group: destructive action at bottom
  • "Done" button: saves changes and returns to previous tab

Milestone Coherence Rules

Not all numbers are interesting in all units. Filter by what makes sense:

UnitShowDon't show
secondsRound thousands, powers of 10, repdigits (11111111), Asian lucky (888888)Palindromes, Fibonacci, alternating patterns
minutesSame as secondsSame as seconds
hoursRound hundreds, powers of 10, repdigitsPalindromes, Fibonacci, alternating
daysEverything — palindromes, Fibonacci, powers, round numbers all work at human scaleNothing filtered (days are the most natural unit)
weeksRound hundreds onlyEverything else
monthsRound hundreds + cultural (108, 786, 888)Everything else
yearsEverything (small numbers, all meaningful)Nothing filtered

Unit display names

Full words in all views: "seconds", "minutes", "hours", "days", "weeks", "months", "years". Short forms ("s", "min", "hrs") only in very tight spaces (widgets, share cards).

Share Flow

Sharing is the core viral mechanic. Two contexts:

Onboarding share

  • Tap any milestone row → gold highlight (ms-selected class) + floating "Share →" bubble at bottom center
  • Tap bubble → native share picker
  • Available on all milestone screens (3, 5, 6, 8)

Daily use share

  • Me tab: tap milestone → gold highlight (tc-selected) + sticky share bar above tabs → Share button → native share picker
  • Together tab: tap combined milestone → same flow (gold highlight + sticky share bar above tabs)
  • All shared text also copied to clipboard automatically

Milestone Engine Rules

  • Powers of 2: Uncapped (up to 230)
  • Combined milestones: findSumMilestonesForEvents across seconds/minutes/hours/days/weeks/months/years
  • Patterns found: palindromes, repdigits, Pi, Fibonacci, powers, round numbers, Asian auspicious, sacred numbers
  • Cosmic milestones: max 1 globally, show description only (no redundant number). If the hero reveal shows a cosmic milestone, it also appears in the milestone list below for consistency.
  • Date formatting: ordinal suffixes ("Sep 7th"), year only if different from current year
